# Security Policy

## Supported versions

Only the latest published BlendLib alpha for Minecraft 26.1.2 is eligible for security fixes.
Alpha APIs may change while a fix is developed.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Contact LIy-hub at
`2734855720@qq.com` with the affected version, reproduction steps, impact, and any proposed
mitigation. Remove world saves, access tokens, personal data, and third-party secrets from reports.

Receipt should be acknowledged within seven days. Validation, remediation, coordinated disclosure,
and release timing depend on severity and reproducibility; no bounty or fixed resolution deadline is
promised.

Visual model data and animation events are never a trusted source for server-authoritative gameplay.
Reports that cross resource-path, archive, parser-limit, client/server, or network boundaries are
especially useful.
