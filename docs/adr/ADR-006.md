# ADR-006: No direct raw OpenGL

Status: Accepted

## Decision

BlendLib rendering uses Minecraft and Blaze3D abstractions rather than raw OpenGL calls.

## Rationale

This follows Minecraft backend abstraction, reduces conflicts with Iris and Sodium, and keeps a future backend transition possible.

## Consequences

Adapter implementations are verified against the current Minecraft renderer API instead of copying fixed low-level GL code.
