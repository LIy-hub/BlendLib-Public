# ADR-003: Textures are external Minecraft resources

Status: Accepted

## Decision

GLB carries geometry, hierarchy, skin, animation, and material-slot names; Minecraft resource identifiers provide runtime textures.

## Rationale

External textures support resource-pack override, TextureManager lifecycle, Iris and standard RenderType compatibility, and avoid duplicate registration of embedded GLB images.

## Consequences

V1 rejects embedded images as material sources. Descriptor material mappings point to external Minecraft PNG resources.
