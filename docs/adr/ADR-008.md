# ADR-008: V1 state machines have no expression DSL

Status: Accepted

## Decision

Each v1 instance has one main controller with explicit trigger, loop, speed, automatic next state, and blend behavior. V1 includes no expression language.

## Rationale

Business mods decide conditions such as attack, walking, or hit response. BlendLib reliably plays and interpolates the requested state without introducing a hard-to-debug scripting language.

## Consequences

V1 excludes conditional-expression DSLs, multiple-controller blending, additive pose layers, bone masks, and root-motion authoritative movement.
