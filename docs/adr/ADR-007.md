# ADR-007: One Fabric runtime artifact per Minecraft version

Status: Accepted

## Decision

Each Minecraft target receives a distinct Fabric runtime artifact.

## Rationale

Rendering classes and method signatures are not assumed binary-stable across Minecraft minor versions.

## Consequences

26.1.2 is the first runtime adapter. A later 26.2 adapter reuses core fixtures and public compile tests but supplies its own rendering integration and JAR.
