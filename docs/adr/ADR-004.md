# ADR-004: Resources, instances, and snapshots are separate layers

Status: Accepted

## Decision

Immutable shared model resources, per-instance controller state, and immutable render snapshots are distinct data layers.

## Rationale

The separation supports many independent instances, thread isolation, bounded caching, hot reload lifecycle, and a future GPU backend.

## Consequences

ModelAsset never carries entity or world state. Rendering consumes snapshots and does not read mutable entity, world, or network state during submit.
