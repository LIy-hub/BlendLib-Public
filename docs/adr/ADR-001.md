# ADR-001: Runtime format uses GLB 2.0

Status: Accepted

## Decision

BlendLib v1 uses GLB 2.0 as its runtime model container. Blender source files remain art inputs and are not runtime resources.

## Rationale

GLB is single-file, suitable for runtime distribution, natively exported by Blender, and can express geometry, nodes, skins, and animation. The source .blend remains the authoring format.

## Consequences

Runtime code does not parse .blend, FBX, or OBJ. Asset behavior is validated against the strict v1 GLB archive.
