# ADR-002: Only explicit strict profiles are supported

Status: Accepted

## Decision

BlendLib v1 supports only the explicitly declared rigid_v1 and skinned_v1 GLB profiles.

## Rationale

Full glTF support is too broad for v1, and resource-pack assets are untrusted input.

## Consequences

Unsupported glTF features, required extensions, malformed accessors, and security-limit violations produce stable diagnostics rather than best-effort implicit behavior.
