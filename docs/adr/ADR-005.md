# ADR-005: Rendering is client-only; animation semantics may synchronize from the server

Status: Accepted

## Decision

The server owns business decisions and may synchronize animation semantics. Client code owns model parsing during client reload, instance playback, snapshots, and rendering.

## Rationale

This separates authoritative gameplay from visual rendering while keeping network traffic stable and dedicated servers safe.

## Consequences

Payloads carry target, animation key, start tick, sequence, seed, speed, and persistence semantics, never vertices, bone palettes, or GLB bytes.
