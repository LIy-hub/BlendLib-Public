`feature/mc26.3-animation-capabilities`. Work is stacked on

and restoration of the exact same sequence. Resume the accepted absolute timeline
without accepting older sequences or conflicting same-sequence payloads. Retain
visual-event high-water marks, suppress history skipped during fallback, and keep

Add an explicitly enabled, separately packaged example consumer to the modern
26.3 build. Demonstrate entity layers, a procedural pose, a final-pose socket
attachment, and an animated handheld item. Keep example entrypoints and assets
out of the normal library JAR. Supply small deterministic assets, exact launch
and installation commands, and in-world summon/give instructions.

## Stage 3 — verify and deliver

Check the focused runtime regressions, example compilation and resource/packaging
boundaries. Perform one critical review, push the new branch, and follow the
exact commit's CI to completion, fixing relevant failures. Native world/visual
verification is reported only if actually run; no unattended EULA acceptance,
release, tag, CurseForge upload, or public API break is part of this batch.
