# Explicit assembly culling envelope (Minecraft 26.3)

## Inspection and bounded plan

The ordinary entity builder currently has no assembly bounds option. Culling resolves the
current root handle before extraction; attachment snapshots therefore cannot repair a rejected
frustum test. Existing root-rotation configuration only expands the root handle envelope.

1. Add an immutable finite `BlendEntityCullingEnvelope` in entity-local block units and an
   optional ordinary builder setting. Capture it at build time without an entity callback.
2. Union its rotation-invariant conservative cube with vanilla and current-generation root
   bounds in the existing culling entry. Support yaw and arbitrary normalized root rotation
   without invoking selectors, animation or attachment providers. Keep old descriptors and
   behavior; mirror constructor plumbing in legacy adapters.
3. Document pre-root-rotation coordinates, authored units conversion, instance offsets/scales,
   custom snapshot responsibility, renderer lifetime/reload, finite/ordered input rejection
   and finite fail-safe for invalid world coordinates. No global culling bypass.
4. Exercise an explicitly selected extended attachment mode in the runnable example, reusing
   existing assets and specifying a conservative envelope; no fake bounds geometry.
5. Test real culling-entry wiring, transformed attachment vertices, rotation, instance positions,
   reload, immutable capture, malformed input, old behavior and hidden render suppression.
   Pin additive ABI, run official 26.3 build and JAR verification, root checks, and one focused
   review. Native graphics acceptance remains deferred, not passed.
6. Push only this independently named stacked branch, wait for terminal exact-head CI, and
   provide the cumulative source/JAR/evidence Library bundle. No merge, release or tags.
