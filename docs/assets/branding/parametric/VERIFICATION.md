# 参数化矢量初次交付验证

验证日期：2026-09-13。范围为本目录的独立图标重构、生成脚本和交付文件。

## 可复现性

- Python 3.11.15 下，在两个独立输出目录分别生成。3 份符号 SVG、构造图 SVG、
  `geometry.json`、`manifest.json`、`SHA256SUMS` 共 7 个文件逐字节相同，
  且与交付目录一致。
- 将脚本、参数和 reference 文件夹复制到另一个目录，以 `python -S` 禁用
  第三方包后从零生成，7 个文件仍逐字节相同。
- `python generate.py --check` 通过。向测试目录中的 SVG 追加一个换行后，
  检查正确失败，且没有改写被检查文件。
- 核心清单中的每项 SHA-256 与实际字节核对一致。
- 机器可读记录：[verification-report.json](./verification-report.json)。

## 参数和 SVG 结构

- 检查了 7 组有效参数变更：输出单位、较小/较大孔间距、立柱宽、孔水平距离、
  回折投影距离、斜率。每组重新生成并通过 `--check`。
- 将单位从 32 改为 16，固有尺寸从 1152 px 变为 576 px；`viewBox` 和全部路径不变。
- 5 组无效输入均在写入输出目录前被拒绝：折面塌陷、负输出单位、画布不足、
  非有限数字、左侧角点次序反转。
- 透明母版、白底版与紧边界版的 3 个填充路径属性完全相同。差别只在画布、平移和背景。
- 母版中无 raster image、文字绘制、字体依赖、脚本、滤镜、渐变或外部引用。
  路径闭合，元素 ID 唯一；主体复合路径用 evenodd 规则构造两个孔。

## 实际渲染与视觉复核

- 使用 PyMuPDF 1.28.0 渲染实际 SVG，以 Pillow 12.2.0 合成预览。
- 768 px 透明渲染中，两个三角孔的重心处 Alpha 都为 0。
- 透明母版合成到白底后，与白底 SVG 的渲染最大 RGB 通道差均为 2/255，
  位于抗锯齿边缘；白底和透明版共用相同矢量几何。
- 16、24、32、48、64、128 px 均已渲染并放入对照图；以 Alpha=128 为阈值、
  四邻接方式统计，各尺寸均有 2 个封闭透明孔。这个数值不等于人眼可读性评分。
- 已查看原图/重构对照、缩小预览和完整构造图。轮廓、两孔和两处折面保留；
  构造图网格越界问题已修复并重新查看。16 px 的折面细节有限，32 px 以上更清楚。
- 栅格校验与预览哈希：[proof-report.json](./generated/proof-report.json)。
