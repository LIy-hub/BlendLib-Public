# 带字母版验证记录

验证日期：2026-09-13。以下为本目录带字母版及生成流程的验证。
后续正式资源同步的检查见 [正式化记录](../wordmark-adoption-2026-09-13.md)。

## 真实字体与文字内容

- 用户确认组合为折面 B + `lendLib`，整体读作 `BlendLib`。
- 字体副本与用户提供的 Minecraft.otf 逐字节一致；许可文件原样保留。
- HarfBuzz 的七个字符与轮廓顺序为 `l e n d L i b`；Glyph ID 依次为
  `77, 70, 79, 69, 45, 74, 67`。未出现缺字、替代字形或大小写变化。
- SVG 母版只有 10 个闭合填充路径，其中 7 个来自原字体 CFF 轮廓。
  没有活文字、字体引用、位图、脚本、描边、滤镜或辅助网格。
- 通过 FreeType 直接渲染原字体，再与实际 SVG 渲染的文字 Alpha 逐像素比较：
  原尺寸 **0 个差异像素**。这项比较使用两套渲染途径，原字体渲染未读取 SVG 路径数据。

## 图形、透明度与边缘

- B 采用 17 个共享顶点，所有斜边为 ±1/2 斜率；两个三角孔相同。
- 原尺寸 PNG 为 **3066 × 1022 / RGBA**，四个画布角和两个三角孔重心 Alpha 均为 0。
- 字体轮廓顶点全部落在整数像素上。文字 Alpha 仅含 0、255，没有半透明灰边。
  B 的斜边仍正常抗锯齿。
- 七个字形使用公共基线，x/y 等比缩放；可见间距统一为 3.5u。
- 文字基线下移 +1u、每个字体间隔增加 2/7u 的修正已进入参数说明与尺寸表。
- 已查看白底展示预览、原字体轮廓比对图、原图对照及独立构造图。
  规范图中基线标签的位置已调整并复查，辅助线与标签未写入母版。

机器可读渲染结果：[render-report.json](./generated/render-report.json)。

## 生成与参数验证

- 在两个独立输出目录分别生成，全部 14 个输出与交付目录逐字节一致，包括 SVG、PNG、表格和清单。
- 将脚本、参数和源资产复制到新目录后从零生成，14 个输出仍逐字节一致。
- `--check` 通过。给测试 SVG 追加一个换行后，检查正确失败且未改写被检查的文件。
- 另做 5 组完整生成：字距 4u、文字高 16.5u、基线修正 0.5u、两孔间距 0.5u、
  输出单位 56 px/u。各组均生成 SVG/PNG，文字与原字体渲染仍为 0 个 Alpha 差异像素。
- 字距 4u 的输出为 3150 × 1050；文字高 16.5u 的输出为 3234 × 1078；
  56 px/u 的输出为 6132 × 2044，局部 u 坐标未变。
- 6 组无效输入在写入输出目录前被拒绝：改变文字大小写、折面塌陷、非整数输出画布、
  留白不足、无效颜色、源字体哈希不符。
- 所有生成清单 SHA-256 与交付文件核对一致。

机器可读检查结果：[verification-report.json](./verification-report.json)。

Python 3.11.15；fontTools 4.65.0、uharfbuzz 0.56.1、PyMuPDF 1.28.0、Pillow 12.2.0。
