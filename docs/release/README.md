## Alpha 提示

这是早期测试版本，API 与行为可能变化，请勿用于关键生产环境。只支持声明的 Minecraft
26.1.2、Fabric Loader 0.19.3、Fabric API `0.154.2+26.1.2` 与 Java 25 环境。

26.1.2 runtime、sources、Javadoc、Showcase、Blender Add-on ZIP、Local Maven 与库存文件由
`buildRelease` 生成。
