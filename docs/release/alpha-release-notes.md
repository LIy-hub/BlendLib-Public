# BlendLib 1.0.0-alpha.1+26.1.2

BlendLib 的首个公开 Alpha 面向 Minecraft 26.1.2 Fabric 开发者，提供严格 GLB 2.0
资源加载、rigid/skinned 模型、动画语义、实体/方块实体/item client adapter、诊断工具与
独立 Showcase。runtime JAR 内嵌 BlendLib API、core 与 common 模块；sources、Javadoc、
Local Maven 和 Blender 导出 Add-on 作为独立制品准备。

## 兼容性

- Minecraft 26.1.2
- Fabric Loader 0.19.3
- Fabric API `0.154.2+26.1.2`
- Java 25
- 严格 GLB 2.0；不支持 `.blend`、FBX、OBJ 或 26.2 运行时

## Alpha 警告

这是早期测试版本，API 与行为可能变化，请勿用于关键生产环境。仅支持上方声明的
Minecraft 26.1.2、Fabric 与 Java 环境。

非 Add-on 源码使用 Apache-2.0；Blender Add-on 独立使用 GPL-3.0-or-later。
源码与问题：[GitHub](https://github.com/LIy-hub/BlendLib-Public)；发布页：
